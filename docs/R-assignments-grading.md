# R. تکلیف، آزمون و نمره‌دهی — Assignments & Grading

> الحاقیه بر A–P. بخش آموزشیِ محصول: از دادن تکلیف تا نمرهٔ نهایی ترم.

---

## R.1 اصل حاکم

**سریع‌ترین مسیر تصحیح برنده است.**

مدرس زبان معمولاً پاره‌وقت است، در دو یا سه آموزشگاه کار می‌کند، و تصحیح را شب و در
خانه انجام می‌دهد. اگر تصحیح در محصول ما کندتر از یک دفتر یا یک فایل ورد باشد، مدرس
تکلیف نمی‌دهد — و بدون تکلیف، نصف ارزش آموزشی پلتفرم از بین می‌رود.

معیار: **تصحیح یک تکلیف نوشتاری برای ۱۸ نفر، زیر ۱۵ دقیقه.** یعنی کمتر از ۵۰ ثانیه
برای هر نفر، شامل خواندن، نمره، و بازخورد.

راهی که به این عدد می‌رسد، از Canvas SpeedGrader آمده و سه جزء دارد:
۱. یک صفحه، یک زبان‌آموز، بدون رفت‌وبرگشت به فهرست
۲. روبریک کنار کار، نمره با کلیک روی خانه، جمع خودکار
۳. کلید بعدی/قبلی که فوراً به دانش‌آموز بعدی می‌رود

## R.2 انواع تکلیف

آموزش زبان چهار مهارت دارد و هر کدام شکل تحویل خودش را می‌خواهد. این جدول تفاوت ما
با یک LMS عمومی است:

| نوع | تحویل | تصحیح | مهارت |
|---|---|---|---|
| **نوشتاری** | متن در ویرایشگر یا فایل | حاشیه‌نویسی روی متن + روبریک | Writing |
| **صوتی (گفتار)** | ضبط مستقیم در مرورگر | پخش با نشانه‌گذاری زمانی + روبریک | **Speaking** |
| **پاسخ به فایل صوتی** | شنیدن فایل، پاسخ کوتاه | خودکار یا دستی | Listening |
| **پرسش‌های بسته** | چندگزینه‌ای، جای خالی، تطبیق | **خودکار** | Grammar / Vocab |
| **آپلود فایل** | عکس دفتر، PDF، اسکن | مشاهده + نمره | تمرین کتاب |
| **پروژه / ارائه** | فایل + توضیح | روبریک | تلفیقی |
| **بدون تحویل** | فقط اعلام («صفحهٔ ۳۲ تا ۳۸ را بخوانید») | فقط انجام‌شده/نشده | مطالعه |

### تکلیف صوتی — مهم‌ترین نوع برای آموزشگاه زبان

هیچ LMS عمومی این را درست انجام نمی‌دهد و برای آموزش زبان حیاتی‌ترین است:

- زبان‌آموز مستقیم در مرورگر ضبط می‌کند، بدون نصب هیچ برنامه‌ای
- محدودیت زمان قابل تنظیم (پیش‌فرض ۳ دقیقه) و امکان چند تلاش
- مدرس هنگام پخش می‌تواند **روی ثانیهٔ مشخص یادداشت بگذارد**:
  «۰۰:۴۲ — تلفظ /θ/ اینجا اصلاح شود»
- زبان‌آموز موقع پخش، یادداشت‌ها را روی نوار زمان می‌بیند
- مدرس می‌تواند **بازخورد صوتی** ضبط کند — سریع‌تر از تایپ فارسی/انگلیسی و برای
  اصلاح تلفظ به‌مراتب مؤثرتر
- حجم: فشرده‌سازی سمت کلاینت قبل از آپلود، وگرنه ۱۸ فایل ۳ دقیقه‌ای در هر جلسه،
  فضا و پهنای باند را می‌خورد

## R.3 مدل داده — الحاقیه بر بخش I

### `ASSIGNMENT` (گسترش‌یافته)
```
id · institute_id · class_id · term_id
title · description · instructions_rich
type            writing | speaking | listening | quiz | file | project | reading
attachments[]   فایل‌های پیوست مدرس
assigned_at · due_at · close_at        close_at: بعد از آن اصلاً نمی‌شود فرستاد
allow_late · late_penalty_percent_per_day · max_late_days
max_score · weight_in_component        به کدام بخش دفتر نمره وصل است
rubric_id                              nullable
submission_config (JSONB)
    نوشتاری : min_words, max_words, allow_file, editor_mode
    صوتی    : max_seconds, max_attempts, allow_rerecord
    آزمون   : question_ids[], shuffle, time_limit, attempts, show_answers_when
    فایل    : accepted_types[], max_size_mb, max_files
visibility      draft | published | closed
publish_grades_at   دستی یا زمان‌بندی‌شده
peer_review_enabled · peer_review_count
created_by · status
```

### `RUBRIC` و `RUBRIC_CRITERION`
```
RUBRIC
  id · institute_id · name · description · total_points
  is_template · level_id (nullable)    قالب آماده برای هر سطح
  created_by

RUBRIC_CRITERION
  id · rubric_id · title            مثلاً «روانی»، «دقت گرامری»، «تلفظ»
  description · weight_points · sequence
  levels (JSONB)                    [{label:"عالی", points:5, descriptor:"..."}, …]
```

**قالب‌های آمادهٔ روبریک که باید در MVP باشند** — چون هیچ مدرسی از صفر روبریک نمی‌سازد:
- **Writing عمومی:** محتوا · انسجام · واژگان · گرامر · نگارش
- **Speaking عمومی:** روانی · تلفظ · واژگان · گرامر · تعامل
- **IELTS Writing Task 2:** Task Response · Coherence & Cohesion · Lexical Resource · Grammatical Range
- **IELTS Speaking:** Fluency · Lexical Resource · Grammar · Pronunciation
- **کودکان:** مشارکت · تلاش · انجام تکلیف

### `SUBMISSION` (گسترش‌یافته)
```
id · institute_id · assignment_id · student_id · enrolment_id
attempt_number · content_text · word_count
attachments[]        {url, type, size, duration_seconds}
audio_url · audio_duration_seconds · audio_waveform (JSONB)
quiz_answers (JSONB) · auto_score
submitted_at · is_late · days_late
state           not_started | draft | submitted | returned | graded | resubmit_requested
score · penalty_applied · final_score
rubric_scores (JSONB)    {criterion_id: {points, comment}}
feedback_text · feedback_audio_url
inline_annotations (JSONB)   نوشتاری: {from, to, note} | صوتی: {at_second, note}
graded_by · graded_at · returned_at · viewed_by_student_at
```

`viewed_by_student_at` کوچک ولی مهم است: مدرس می‌خواهد بداند بازخوردش خوانده شده یا نه.

### `GRADE_COMPONENT` (از بخش I، با یک تغییر)
اضافه می‌شود: `source (manual | assignments | quizzes | attendance | exam)`.
اگر یک بخش دفتر نمره از تکالیف تغذیه شود، نمره‌اش خودکار از میانگین تکالیف همان بخش
محاسبه می‌شود — و مدرس می‌تواند بازنویسی کند (با ثبت دلیل).

### قواعد تعاملی

| قاعده | چرا |
|---|---|
| کلیک روی خانهٔ روبریک = نمره. جمع خودکار | تایپ عدد کند است و اشتباه می‌آورد |
| `Ctrl+Enter` = ثبت و بعدی | تصحیح‌کنندهٔ حرفه‌ای دستش از کیبورد جدا نمی‌شود |
| ذخیرهٔ خودکار پیش‌نویس هر ۵ ثانیه | بستن تصادفی تب نباید ۲۰ دقیقه کار را ببرد |
| نمره تا **انتشار** برای زبان‌آموز دیده نمی‌شود | مدرس می‌خواهد کل کلاس را ببیند بعد منتشر کند |
| **عبارت‌های آماده** قابل ذخیره | «به فعل گذشتهٔ نامنظم دقت کن» بیست بار در ترم تکرار می‌شود |
| بازخورد صوتی حداکثر ۲ دقیقه | سریع‌تر از تایپ و برای تلفظ مؤثرتر |
| تصحیح ناشناس (اختیاری) | برای آزمون‌های مهم، حذف سوگیری |
| فیلتر: تصحیح‌نشده · دیرکرد · تحویل‌نشده | مدرس معمولاً فقط تصحیح‌نشده‌ها را می‌خواهد |
| تحویل‌نشده‌ها هم در صف می‌آیند | تا مدرس بتواند صفر بدهد یا مهلت بدهد، بی‌آنکه دنبالشان بگردد |
| کار روی موبایل | مدرس در تاکسی تصحیح می‌کند. زیر ۷۶۸ پیکسل روبریک زیر کار می‌آید |

## R.5 جریان کار تکلیف

```
── مدرس: ساخت ──
۱. کلاس → تکالیف → «تکلیف جدید»
۲. نوع را انتخاب می‌کند → فرم متناسب همان نوع باز می‌شود (نه یک فرم عمومی)
۳. عنوان، توضیح، پیوست، مهلت (تاریخ شمسی)، نمره، روبریک
   ⤷ «از تکلیف قبلی کپی کن» — بیشتر تکالیف تکرارشونده‌اند
   ⤷ «به بخش دفتر نمره وصل کن»: تکالیف | آزمونک | میان‌ترم
۴. «انتشار» یا «زمان‌بندی برای بعد»
   ⚙ اطلاع درون‌برنامه‌ای + پیامک (اختیاری) به زبان‌آموزها
   ⚙ در پرتال زبان‌آموز زیر «تکالیف پیش‌رو» می‌آید

── زبان‌آموز: تحویل ──
۵. پرتال → تکلیف → بسته به نوع:
   نوشتاری → ویرایشگر با شمارندهٔ کلمه و ذخیرهٔ خودکار
   صوتی    → دکمهٔ ضبط، پیش‌نمایش، امکان ضبط دوباره تا سقف تلاش
   آزمون   → یک سوال در هر صفحه، ذخیرهٔ خودکار، تایمر
   فایل    → آپلود با نمایش پیشرفت
۶. «ارسال» → تأیید نهایی («بعد از ارسال نمی‌توانید تغییر دهید» اگر چنین است)
   ⚙ رسید تحویل با زمان دقیق
   ⚠ بعد از مهلت: اگر دیرکرد مجاز است، هشدار جریمه قبل از ارسال نشان داده می‌شود
   ⚠ بعد از close_at: ارسال بسته است، ولی دکمهٔ «درخواست تمدید» هست

── مدرس: تصحیح ──
۷. پنل مدرس → «کارهای مانده» → «۶ تکلیف تصحیح‌نشده» → صفحهٔ تصحیح (R.4)
۸. تصحیح، بعدی، بعدی…
۹. «انتشار نمرات» برای کل کلاس
   ⚙ اطلاع به زبان‌آموزها
   ⚙ نمره‌ها به دفتر نمره می‌روند و نمرهٔ جاری ترم به‌روز می‌شود

── زبان‌آموز: بازخورد ──
۱۰. نمره، روبریک با خانهٔ انتخاب‌شده، یادداشت‌های درجا، بازخورد متنی و صوتی
    ⤷ «درخواست بازبینی» اگر آموزشگاه فعال کرده باشد
```

## R.6 نمره‌گذاری خودکار

| نوع سوال | خودکار؟ |
|---|---|
| چندگزینه‌ای | ✅ |
| چند پاسخ درست | ✅ با نمرهٔ جزئی |
| درست/غلط | ✅ |
| تطبیق | ✅ |
| جای خالی | ✅ با فهرست پاسخ‌های پذیرفتنی + چشم‌پوشی از حروف بزرگ/کوچک و فاصله |
| مرتب‌سازی جمله | ✅ |
| پاسخ کوتاه | ⚠️ پیشنهاد خودکار + تأیید مدرس |
| انشا | ❌ دستی |
| صوتی | ❌ دستی (ارزیابی خودکار گفتار: فاز آینده، بند L.5) |

**قاعده:** نمرهٔ خودکار همیشه قابل بازنویسی توسط مدرس است، و هر بازنویسی در تاریخچه
می‌ماند. زبان‌آموز فارسی‌زبان که در جای خالی «go**es**» را با فاصلهٔ اضافه نوشته،
نباید صفر بگیرد.

## R.7 سیاست دیرکرد و تقلب

**دیرکرد** — به‌ازای هر تکلیف قابل تنظیم:
- بدون پذیرش دیرکرد
- پذیرش با جریمهٔ درصدی روزانه (پیش‌فرض ۱۰٪، سقف ۵۰٪)
- پذیرش بدون جریمه، فقط با نشان «دیرکرد»
- مهلت جداگانه برای یک زبان‌آموز خاص (بیماری، سفر) با ثبت دلیل

**تشابه متن** — نه یک سیستم ضدسرقت ادبی کامل:
- مقایسهٔ تحویل‌های همان تکلیف با یکدیگر و با ترم‌های قبل
- درصد تشابه به مدرس نشان داده می‌شود، **بدون هیچ اتهامی و بدون اقدام خودکار**
- در آموزش زبان، شباهت جملات سطح مبتدی طبیعی است؛ عدد فقط برای نگاه مدرس است
- تشخیص متن تولیدشده با هوش مصنوعی: **عمداً نمی‌سازیم.** دقتش کافی نیست و
  اتهام اشتباه به یک زبان‌آموز، آسیبش از فایده‌اش بیشتر است

## R.8 دفتر نمره و نمرهٔ نهایی

```
نمرهٔ نهایی ترم = Σ (نمرهٔ هر بخش × ضریب بخش)

بخش‌های پیش‌فرض یک آموزشگاه زبان ایرانی:
  تکالیف و کلاس‌کار   ۲۰٪   ← از میانگین تکالیف
  آزمونک              ۱۵٪   ← از میانگین آزمونک‌ها
  میان‌ترم             ۲۵٪   ← دستی یا از آزمون
  پایان‌ترم            ۳۰٪   ← دستی یا از آزمون
  مشارکت و حضور       ۱۰٪   ← دستی، با پیشنهاد از درصد حضور
```

- مقیاس پیش‌فرض **۰ تا ۲۰** (بند P.5)
- جمع ضرایب باید دقیقاً ۱۰۰ شود، وگرنه ستون نمرهٔ نهایی به‌جای عدد، هشدار نشان می‌دهد
- حد قبولی قابل تنظیم؛ پیش‌فرض ۱۲ از ۲۰
- **قاعدهٔ ارتقای سطح:** قبولی + حداقل درصد حضور. اگر هر دو برقرار باشد، در تمدید ترم
  سطح بعدی پیشنهاد می‌شود؛ وگرنه تکرار همان سطح — این همان چیزی است که بند G.11 را
  تغذیه می‌کند
- کارنامهٔ قابل چاپ با لوگوی آموزشگاه، نمرهٔ هر بخش، درصد حضور، و نظر مدرس

## R.9 حالت‌های مرزی

| مورد | رفتار |
|---|---|
| زبان‌آموز وسط ترم اضافه شد | تکالیف قبل از ثبت‌نامش `not_applicable`، نه صفر |
| زبان‌آموز انصراف داد | تکالیف باقی‌مانده از میانگینش حذف می‌شوند |
| تکلیف بعد از تحویل چند نفر ویرایش شد | هشدار به مدرس با تعداد تحویل‌های موجود؛ تغییر نمرهٔ کل، نمره‌های داده‌شده را بازمحاسبه می‌کند و ثبت می‌شود |
| مدرس وسط ترم عوض شد | مدرس جدید به تصحیح‌های قبلی دسترسی دارد؛ نام تصحیح‌کنندهٔ هر مورد محفوظ می‌ماند |
| آپلود صوتی نصفه قطع شد | آپلود تکه‌ای با ادامه از همان‌جا؛ زبان‌آموز ضبط را از دست نمی‌دهد |
| میکروفن اجازه نداشت | راهنمای تصویری فعال‌سازی + گزینهٔ «آپلود فایل صوتی» به‌جای ضبط |
| نمره منتشر شد و اشتباه بود | اصلاح با تأیید مدیر آموزشی؛ زبان‌آموز از تغییر مطلع می‌شود؛ نمرهٔ قبلی در تاریخچه می‌ماند |
| زبان‌آموز اصلاً تحویل نداد | در صف تصحیح می‌آید تا مدرس صفر بدهد یا مهلت بدهد — نه اینکه فراموش شود |
| دو تلاش برای تکلیف صوتی | آخرین تلاش ملاک است مگر مدرس دستی انتخاب کند |
| مهلت روی تعطیلی افتاد | هشدار موقع ساخت تکلیف با تقویم شمسی و پیشنهاد روز بعد |

## R.10 جایگاه در نقشهٔ راه

| قابلیت | فاز |

| تکلیف نوشتاری، فایل، بدون تحویل + تحویل + تصحیح ساده | **MVP** |
